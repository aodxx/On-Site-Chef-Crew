# On-Site Chef & Crew

ศูนย์กลางการพัฒนาธุรกิจบริการทีมแม่ครัว/พ่อครัวเฉพาะกิจสำหรับงานบุญ งานพิธี งานศพ และงานเลี้ยงในพื้นที่จังหวัดพัทลุงและพื้นที่ใกล้เคียง

## เป้าหมายของ Repository นี้

Repository นี้ไม่ใช่โปรเจกต์ซอฟต์แวร์ แต่เป็น **Business Operating System** สำหรับเจ้าของธุรกิจและทีม AI เพื่อใช้เป็นแหล่งข้อมูลกลางในการคิด วิเคราะห์ ตัดสินใจ และพัฒนาธุรกิจอย่างต่อเนื่อง

เป้าหมายสำคัญคือให้ AI หรือผู้ร่วมงานคนใหม่สามารถเข้ามาอ่านเอกสารแล้วเข้าใจได้ทันทีว่า:
- ธุรกิจนี้กำลังสร้างอะไร
- ลูกค้าคือใคร
- ปัญหาใดที่เราต้องการแก้
- บริการปัจจุบันคืออะไร
- อะไรยังเป็นเพียงสมมติฐาน
- ตอนนี้ธุรกิจอยู่ Phase ไหน
- งานใดควรทำต่อ

## สถานะปัจจุบัน

**Stage:** Business Discovery / Phase 0 — Business Foundation

ธุรกิจยังอยู่ในขั้นนิยามบริการ ยังไม่ได้กำหนดชื่อแบรนด์ ราคา แพ็กเกจบริการ หรือกระบวนการรับงานอย่างเป็นทางการ

## หลักการสำคัญ

- ห้ามถือว่าสมมติฐานเป็นข้อเท็จจริง
- ห้ามเปลี่ยนทิศทางธุรกิจหลักโดยไม่บันทึกเหตุผล
- การระดมสมองต้องแยกออกจากการตัดสินใจ
- การตัดสินใจสำคัญของธุรกิจเป็นสิทธิ์ของ Business Owner
- ทุกข้อเสนอควรคำนึงถึงบริบทจริงของงานบุญ งานพิธี งานศพ และชุมชนในพัทลุง
- ยังไม่เร่งทำ Branding หรือ Pricing จนกว่าจะเข้าใจบริการและต้นทุนจริงพอสมควร

## Workflow ของทีม AI

Idea → Research → Proposal → Discussion → Decision → Implementation → Review

เมื่อมีการตัดสินใจสำคัญ ให้บันทึกไว้ใน `decisions/`
เมื่อมีแนวคิดที่ยังไม่ได้อนุมัติ ให้บันทึกไว้ใน `proposals/`
เมื่อทำการทดลองจริง ให้บันทึกไว้ใน `experiments/`

## เจ้าของธุรกิจ

บทบาทของเจ้าของธุรกิจคือ **Business Owner / Final Decision Maker**
AI มีหน้าที่ช่วยคิด วิเคราะห์ เปรียบเทียบ วางระบบ และเสนอทางเลือก ไม่ใช่ตัดสินใจแทนเจ้าของในเรื่องสำคัญ
